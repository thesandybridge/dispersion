# Dispersion

Two builds of the same golf shot-dispersion app:

- [`app/`](./app/) — Tauri + React + TypeScript desktop/mobile build (the working reference implementation).
- [`ios/`](./ios/) — native SwiftUI port targeting iOS 17+ (iPhone & iPad). Scaffold + first-pass screen ports.
- [`_reference/design_handoff_dispersion/`](./_reference/design_handoff_dispersion/) — design handoff materials.

Each subproject has its own README with build/run instructions.
